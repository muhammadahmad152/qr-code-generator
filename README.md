# 📱 QR Code Generator

A modern and responsive **QR Code Generator** built with HTML, CSS, and JavaScript.

This web application allows users to enter text or a URL and generate a QR code dynamically. The generated QR code can also be downloaded for later use.

---

## ✨ Features

- 🔳 Generate QR codes from text or URLs
- ⚡ Dynamic QR code generation
- 💾 Download generated QR codes
- 🌓 Dark / Light theme toggle
- 🎨 Modern futuristic interface
- 📱 Fully responsive design
- 🖥️ Desktop and mobile friendly
- ⌨️ Simple and intuitive user interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- QR Code Generation Library
